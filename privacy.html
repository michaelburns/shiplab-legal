ShipGuard Privacy Policy

Last updated October 9, 2026

ShipGuard is a Jira Cloud dashboard gadget made by Shiplab. This policy explains what data ShipGuard uses.

What ShipGuard reads

When someone views a dashboard with the ShipGuard gadget, ShipGuard reads Jira issues, their status history, the list of statuses, fields and projects. It reads them as that person, so it only sees what that person can already see in Jira. It uses this data only to calculate the numbers and charts shown in the gadget.

What ShipGuard stores

Only the gadget settings that a dashboard editor saves, such as the chosen projects, the production label and the targets. Jira stores these settings with the dashboard. ShipGuard does not store issue data, personal data or analytics.

Where data goes

Nowhere outside Atlassian. ShipGuard runs entirely on Atlassian’s Forge platform (“Runs on Atlassian”). It makes no calls to external servers and uses no third-party services, tracking or AI models.

Personal data

ShipGuard does not collect, store or share personal data. It does not show user names or email addresses.

Data deletion

Removing the gadget from a dashboard deletes its settings. Uninstalling ShipGuard removes the app and all of its settings.
