ShipGuard how-to

ShipGuard is a Jira Cloud dashboard gadget that shows your defect escape rate, reopen rate and open production bugs.

Add the gadget

  1. Open a Jira dashboard and choose Edit, then Add gadget.
  2. Search for ShipGuard and add it.

Set it up (about a minute)

  1. Projects pick one or more projects.
  2. How production bugs are marked choose a label (for example production), a field value, or any JQL.
  3. Targets set the escape rate and reopen rate you want to stay under.
  4. Save.

Read the numbers

  • Escape rate share of bugs found in production.
  • Reopen rate share of fixed bugs that moved from a Done status back to an open one.
  • Green or red shows each number against your target. The change shows the move since the last sprint, week or month.
  • Use the breakdown to see results by component, sprint, fix version or project. Click any number to open the matching bugs in Jira search.
